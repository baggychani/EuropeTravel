# 지인이와 나의 유럽여행 — 이동 연출 시제품

정적 HTML/CSS/ES modules, Three.js 0.180.0. `node server.mjs` 후 출력된 로컬 주소에서 확인한다.

## 구현 범위

인천 → 바르셀로나(비행), 바르셀로나 ↔ 몬세라트(기차 왕복), 바르셀로나 → 리스본(비행), 리스본 → 카사블랑카(비행), 카사블랑카 → 라바트(기차), 라바트 → 탕헤르(기차), 탕헤르 → 알헤시라스(페리). 8구간.

구간 선택, 재생/일시정지, 다시 재생, 구간 이동, 시간 막대 탐색, 드래그/확대와 전체 보기. 지도·모델·선은 같은 3D 장면이며 경로는 진행에 맞춰 그려진다. 비행기는 공중 곡선, 기차와 페리는 표면 경로를 사용한다. 가까운 지역의 선명도를 위해 별도 지리 텍스처를 사용한다.

출발일 2025-10-18만 확인됐다. 중간 날짜, 실제 정차역, 실제 페리 항구는 확정하지 않았다. 철도·페리 경로는 알려진 지역을 잇는 개략 표현이며 실제 운행 궤적이 아니다. 탕헤르–알헤시라스는 항구가 확인되면 구체화할 것.

날짜 공개는 아직 적용하지 않았다. 사진/편지, 사용자 폰트, 인천 귀환 후 파리 엽서 연출도 이번 범위 밖이다. 최종 사이트는 2026-10-18 첫 공개이며 그 이전의 공개분은 없다.
